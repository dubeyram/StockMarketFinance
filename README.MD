# Stock Market Finance

This project is a collection of Python scripts that demonstrate various stock market analysis techniques. The scripts are designed to be used as a learning tool for beginners and experienced developers alike.

## Scripts

1. **diff_cmp_ath.py**: This script calculates the difference between the current market price (CMP) and the all-time high (ATH) for a given stock. It also calculates the percentage difference between the two values.

2. **diff_cmp_ath_gui.py**: This script is a graphical user interface (GUI) that allows users to enter NSE codes and get the stock information. It uses the yfinance library to fetch the stock data.

3. **stocks_20_50_100_ema.py**: This script calculates the 20-day, 50-day, and 100-day EMAs for a given stock. It uses the yfinance library to fetch the stock data.


4. **requirements.txt**: This file lists the required Python libraries for the project.

5. **README.MD**: This file provides a brief overview of the project and its contents.

## Usage

To use the scripts, follow these steps:

1. Clone the repository to your local machine.

2. Install the required Python libraries by running the following command in your terminal:

   ```
   pip install -r requirements.txt
   ```

3. Run the scripts as Python files. For example, to run the diff_cmp_ath.py script, open your terminal and run:

   ```
   python diff_cmp_ath.py
   ```

4. To run the diff_cmp_ath_gui.py script, open your terminal and run:

   ```
   python diff_cmp_ath_gui.py
   ```

5. To run the stocks_20_50_100_ema.py script, open your terminal and run:

   ```
   python stocks_20_50_100_ema.py
   ```
